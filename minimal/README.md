# lean-worker — Built with gokujo

This project's build infrastructure is generated by a single file: `Gokujo.lean`.

## Stack-Overflow Fix (2026-09-22)

`Gokujo.lean` now uses an **iterative** `walkLean` function with an explicit stack instead of recursion, so it can scan large Lean trees (e.g. `RequestProject` with 663 files) without overflowing.

The fix lives in `Gokujo.lean` at `def walkLean` (lines ~1345). The prebuilt binary at `minimal/gokujo` predates the fix; rebuild it with `gokujo bootstrap` before running full-directory scans.

## Quick Start

```bash
# Generate infrastructure files (uses fixed source via lean --run)
lean --run GokujoMain.lean infra

# Run comprehensive verification
lean --run GokujoMain.lean check minimal/RequestProject

# Build native executable from fixed source
lean --run GokujoMain.lean bootstrap -o gokujo --backend system

# Or use the prebuilt binary (has old walkLean — OK for single files)
./gokujo check minimal/RequestProject
```

## Two-Stage Build Strategy

**Stage 1: Fast iteration (no mathlib, ~5s)**
```bash
lean --run GokujoMain.lean bootstrap -o lean-worker --backend system
lean --run GokujoMain.lean check minimal/RequestProject
```

**Stage 2: Full verification (with mathlib, ~30s)**
```bash
lean --run GokujoMain.lean check minimal/RequestProject --stage full
```

## Agent Workflows

Execute agent workflows using gokujo:
```bash
lean --run GokujoMain.lean exec agent-a
lean --run GokujoMain.lean exec agent-b
lean --run GokujoMain.lean exec agent-c
```

## Docker Build

Build a self-contained container:
```bash
lean --run GokujoMain.lean bundle -o gokujo-bundle ~/.elan/toolchains/leanprover--lean4-v4.28.0
./gokujo-bundle infra
```

## CI/CD Integration

The generated files include:
- `lakefile.toml` - Full build configuration (with mathlib)
- `fast-lakefile.toml` - Fast build configuration (no mathlib)
- `flake.nix` - Nix-based reproducible builds
- `.github/workflows/lean.yml` - GitHub Actions CI
- `pipelight.yml` - pipelight.dev deployment
- `Makefile` - Convenience targets
